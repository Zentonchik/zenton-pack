# Старая сборка (Zenton) — автообновление

Minecraft 1.20.1, Forge 47.4.29. Репозиторий в формате [packwiz](https://packwiz.infra.link/):
здесь только список модов со ссылками на Modrinth и CurseForge, настройки сборки,
собственные переводы и мод Zenton Fix. Сами моды скачиваются с официальных страниц авторов.

Установка — через Prism Launcher: инструкция и файл экземпляра в Discord-канале сборки.
Перед каждым запуском packwiz-installer сравнивает файлы и докачивает только изменённые.
